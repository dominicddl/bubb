## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, icon-to-label gaps |
| md | 16px | Default element spacing, card padding |
| lg | 24px | Section padding inside side panel |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Side panel top/bottom page padding |
| 3xl | 64px | Not used in Phase 1 |

Exceptions: Touch targets for the "Sign in with Google" button must be at least 44px height (accessibility).

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 500 (medium) | 1.4 |
| Heading | 18px | 600 (semibold) | 1.2 |
| Display | 24px | 600 (semibold) | 1.2 |

**Rationale:** Side panels are narrow (default ~320px). 14px body keeps text readable without overflow. 12px labels for secondary info (timestamps, status). Display size used only for the welcome/sign-in screen heading.

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `hsl(0 0% 100%)` / white | Side panel background, popup background |
| Secondary (30%) | `hsl(240 4.8% 95.9%)` | Card backgrounds, input fields, banner backgrounds |
| Accent (10%) | `hsl(222.2 47.4% 51.2%)` | Sign in button, active state indicators, links |
| Destructive | `hsl(0 84.2% 60.2%)` | Error banners, sign-out action |

Accent reserved for: "Sign in with Google" primary CTA button, retry button in error banner, text links, focus rings on interactive elements. Nothing else.

**Dark mode:** Not in Phase 1 scope. Extension uses light mode only. Dark mode is a future enhancement.

## Component Inventory (Phase 1)

These are the UI surfaces built in this phase. Each maps to a shadcn component or custom composition.

### Side Panel — Signed Out State
- Display heading: "Welcome to bubb"
- Body text: sign-in benefit copy
- Google sign-in button (accent color, Google icon from lucide or inline SVG, 44px min height)
- Preview mode badge/label at top

### Side Panel — Signed In State
- Greeting: "Hey, {first_name}"
- Placeholder body: "Your learning dashboard is coming in Phase 2."
- Sign out button (ghost/text style, bottom of panel)
- Usage warning banner (conditional, only at 80%+ cap — amber background)
- Usage limit banner (conditional, only at 100% cap — destructive/red background)

### Popup (Browser Action)
- Compact version of sign-in prompt if not authenticated
- If authenticated: "Open side panel" action or auto-redirect instruction
- Popup max width: 320px, max height: 400px

### Auth Error Banner (Inline)
- Appears at top of side panel
- Dismissible (X button)
- Contains: error icon (lucide `AlertCircle`), message text, retry button
- Background: secondary color with destructive left border (4px)

| Alert | Auth error banner, usage warning, usage limit |
| Badge | Preview mode indicator |
| Separator | Between sections |

## Interaction States

| Interaction | Behavior |
|-------------|----------|
| Sign in button click | Button shows loading spinner, text changes to "Signing in...", disabled state. On success: side panel re-renders to signed-in state. On failure: error banner appears at top. |
| Sign out button click | Confirmation dialog (or inline confirm). On confirm: session cleared, side panel re-renders to signed-out state. |
| Error banner retry | Same loading behavior as sign-in. Banner dismisses on success. |
| Error banner dismiss | X button removes banner. Banner reappears only on next failed auth attempt. |
| Usage warning | Non-dismissible informational banner. Updates count in real-time. |
| Usage limit reached | Non-dismissible blocking banner. Replaces any usage warning. |
