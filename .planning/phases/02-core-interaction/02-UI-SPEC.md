# Phase 2 — UI Design Contract

> Visual and interaction contract for the explanation popup rendered inside Shadow DOM on any webpage. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Typography

All sizes in `px` to avoid rem-based inconsistencies inside Shadow DOM (host page root font-size varies). The shadow root's `:host` sets `font-size: 16px` to normalize any internal rem references from Tailwind.

| Role | Size | Weight | Line Height | Font Family | Usage |
|------|------|--------|-------------|-------------|-------|
| Header | 14px | 600 (semibold) | 1.3 | DM Sans | Highlighted text shown at top of popup (D-07) |
| Body | 14px | 400 (regular) | 1.6 | DM Sans | Explanation text (D-08) |
| Label | 12px | 400 (regular) | 1.4 | DM Sans | Toast copy ("Note saved"), status text |
| Mono | 11px | 400 (regular) | 1.3 | JetBrains Mono | Bracket labels if used (e.g., `[ EXPLAIN ]`) |

Rationale: 14px body keeps the popup compact within the 400x300px constraint (D-10) while remaining readable. Two weights only: 400 (regular) for body, labels, and mono; 600 (semibold) for headers. Label text at 12px already establishes hierarchy through size and muted color -- additional weight differentiation is unnecessary.

## Color

Colors are declared as HSL CSS variables, matching the existing design system in `extension/app.css`. Inside the Shadow DOM, these variables must be re-declared in a `:root` or `:host` scope since they do not inherit from the host page.

| Role | Variable | HSL Value | Hex Approx. | Usage |
|------|----------|-----------|-------------|-------|
| Dominant (60%) | `--card` | 33 20% 97% | #f8f5f0 | Popup card background |
| Secondary (30%) | `--border` | 33 12% 86% | #ddd6cc | Card border, divider between header/body/footer |
| Accent (10%) | `--accent-green` | 142 25% 36% | #458a5c | Save confirmation checkmark, "Note saved" text color |
| Accent action | `--accent-coral` | 4 58% 58% | #ce5a4a | Undo button text, Log in link |
| Foreground | `--foreground` | 24 10% 15% | #2b2623 | Header text (highlighted text), explanation body |
| Muted | `--muted-foreground` | 24 6% 50% | #877f79 | Placeholder text (follow-up input, model selector), close button icon |
| Destructive | `--destructive` | 0 72% 51% | #e03131 | Not used in Phase 2 (no destructive actions in popup) |

Accent reserved for:
- `--accent-green`: Save confirmation checkmark icon, "Note saved" toast text
- `--accent-coral`: Undo button text, "Log in" link in signed-out toast, close button hover state

## Layout Contract

### Popup Dimensions (D-10)

| Property | Value |
|----------|-------|
| Width | 400px (fixed) |
| Max height | 300px |
| Overflow | `overflow-y: auto` on PopupBody only |
| Border radius | 12px (0.75rem, slightly larger than default `--radius` for floating popup feel) |
| Box shadow | `0 4px 24px rgba(0, 0, 0, 0.12)` (subtle elevation over host page content) |
| Border | 1px solid `hsl(var(--border))` |

### Popup Internal Structure

```
+------------------------------------------+  400px wide
| [PopupHeader]                        [X] |  padding: 16px
|   "highlighted text here..."             |  14px semibold, truncated 80 chars
+------------------------------------------+
|                                          |
| [PopupBody] or [SkeletonLoader]          |  padding: 0 16px
|   Explanation text in plain language...  |  14px regular, line-height 1.6
|   Second paragraph if needed.            |  max-height: ~180px, scrollable
|                                          |
+------------------------------------------+
| [PopupFooter]                            |  padding: 8px 16px
|   Ask a follow-up... (disabled)   GPT-4o |  12px muted placeholder
+------------------------------------------+
| [SaveToast]                              |  padding: 8px 16px
|   Note saved [check]     [Undo save]     |  12px, green check, coral undo
+------------------------------------------+
```

### Positioning (D-03)

- Default: 8px below selection `getBoundingClientRect().bottom`
- Horizontal: right-aligned to selection end, clamped 16px from viewport edges
- Flip: if popup would overflow bottom of viewport, position 8px above `selectionRect.top`
- Z-index: `2147483647` (max safe integer, ensures popup is above all host page content)

## Interaction States

### Popup Lifecycle

| State | Visual | Trigger |
|-------|--------|---------|
| Idle | No popup visible | No text selected |
| Loading | Popup with SkeletonLoader in body, header shows highlighted text | mouseup with 3+ char selection (D-01, D-02) |
| Loaded | Explanation text replaces skeleton, SaveToast appears | AI response received |
| Error | Error message in body: "Something went wrong. Try highlighting again." | API failure, network error, timeout |
| Dismissed | Popup removed from DOM | Click outside, Escape, X button, auto-dismiss 30s (D-04) |

### Auto-dismiss Timer (D-04)

- Starts: 30 seconds after popup mounts
- Resets on: any mouseenter, scroll, or click inside the popup
- Clears on: manual dismiss (X, Escape, click outside) or new highlight (D-05)

### Save Toast States

| User State | Toast Copy | Action |
|------------|-----------|--------|
| Signed in, save succeeded | "Note saved" + green checkmark | [Undo save] coral text button |
| Signed in, undo clicked | Toast disappears, note deleted | No further action |
| Signed in, 5s elapsed | Toast fades out | No action (note persisted) |
| Signed out (D-16) | "Sign in to save notes" | [Log in to save] coral text link (opens auth flow) |
| Save failed (network) | "Could not save note" | [Retry save] coral text button |

### Skeleton Shimmer (D-09)

- 3 lines in first paragraph block: 100% width, 83% width, 66% width
- 4px gap between lines (within a paragraph), 16px gap between paragraph blocks
- 2 lines in second paragraph block: 100% width, 75% width
- Animation: CSS `@keyframes pulse` — opacity oscillates between 0.4 and 1.0, 1.5s duration, infinite
- Color: `hsl(var(--muted))` for the shimmer bars

## Shadow DOM Isolation Contract

The popup renders inside a Shadow DOM via WXT's `createShadowRootUi`. This means:

| Concern | Approach |
|---------|----------|
| CSS isolation | `cssInjectionMode: "ui"` injects Tailwind + custom CSS into shadow root only |
| Font loading | Google Fonts `@import` in shadow root's `style.css` (fonts load from CDN, not blocked by shadow boundary) |
| CSS variables | Re-declare all used `--` variables inside shadow root's `:host` or `:root` scope |
| rem normalization | `:host { font-size: 16px; }` to stabilize Tailwind's rem-based utilities |
| Click outside detection | Use `event.composedPath()` to check if click originated inside shadow host (Pitfall 4) |
| Z-index | Shadow host element gets `z-index: 2147483647; position: fixed;` |
